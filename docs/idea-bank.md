# Idea bank

Every idea from our brainstorming, decided or not, so we always have options to pick from or swap in. Decisions that are locked live in [game-design.md](game-design.md); this file is the wider web around them.

**How it works:** every new idea from Bartosz or Claude gets added here with who suggested it and its status. Nothing gets deleted; rejected ideas move to the bottom with the reason.

Status: **In** = in the design · **Maybe** = good candidate · **Event** = better as a limited-time event · **Out** = rejected (with why)

## 2. Why fresh debris is worth more

| Idea | By | Status | Notes |
|---|---|---|---|
| Fragments glow hot and cool down; heat = value | Claude | Maybe (top pick) | Value readable at a glance from the glow, no UI needed |
| Stardust evaporates over time | Claude | Maybe | Pieces visibly shrink |
| Rival crews and scavengers (NPC) pick over old debris | Claude | Maybe | Old piles are less valuable because the good bits are gone |
| City pays a "fast response" bonus that drops each minute | Claude | Maybe | Simple, but less magical |
| Hailstones melt, eggs hatch, teeth crumble (per theme) | Claude | Event | Each event theme brings its own reason |
